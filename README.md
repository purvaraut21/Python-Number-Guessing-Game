# 🎮 Python Number Guessing Game

An interactive GUI-based Number Guessing Game built using Python and Tkinter.

## 📌 Features

- 🎯 Random number generation
- ❤️ Lives/Attempts system
- 🏆 Score tracking
- 🔥 Hint system (“Very Close” feature)
- 🔁 Play Again functionality
- 🖥️ GUI using Tkinter
- 📢 Popup messages using MessageBox
- 🎨 User-friendly colorful interface

---

## 🛠️ Technologies Used

- Python
- Tkinter
- Random Module
- MessageBox
- Functions & Event Handling

---

1. Clone the repository

git clone https://github.com/purvaraut21/Python-Number-Guessing-Game.git
